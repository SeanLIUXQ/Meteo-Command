## 基线实测

使用原始代码、Flask 测试客户端和 CSV 数据复查：

- `/api/manage_city` 接收 JSON `[]` 返回 **500**。
- 只传 `{"action":"add","city":{"name":"example"}}` 被接收为 **200**，没有验证坐标。
- 空降雨数组、null 风速分别触发 **ValueError / TypeError**。
- CSV 中有 **86 个重名名称**；旧搜索“朝阳”仅得到辽宁省结果。
- 原地图有 **385 个节点**，四个直辖市均存在；没有把未经复现的“直辖市缺失”列为缺陷。
- 原 Open-Meteo 请求中 `current.visibility` 在本次实时探测返回 **200**；没有将该参数误报为接口不兼容。

## 运行边界与后续建议

- 当前定位是个人、本机使用的气象看板。收藏属于一个服务实例，尚未提供登录和按用户隔离；默认仅监听回环地址。
- JSON 收藏写入和内存缓存适用于单个应用进程。多进程或多副本应换用 SQLite/数据库与共享缓存，再提供鉴权和限流。
- 本地地图与图表支持不经 CDN 加载；天气和空气数据仍需联网。缓存不能替代实时观测。
- 数据是模式估计/预报，风险提示是规则参考；官方预警源适配需要独立的数据协议与授权。
- CI 提供持续验证路径；某平台有构建脚本不代表已经完成该平台的实际运行验证。具体测试平台以 Release Notes 为准。
